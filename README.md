# Neura

**Phase 1 — Frontend Prototype**

Neura is an AI-Powered 3D Video Generation Platform. This repository contains the Phase 1 implementation which focuses on a polished, professional, responsive frontend experience and a realistic end-to-end clickable prototype using mock data.

## Tech Stack
- Next.js 16.x (App Router)
- React 19.x
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- lucide-react

## How to Install
```bash
npm install
```

## How to Run
```bash
npm run dev
```

## Implementation Notes
- **Phase 1 uses mock generation.** AI APIs (such as LTX, HunyuanVideo, CogVideoX, Gemini, etc.) are intentionally not connected yet.
- The generation flow uses simulated timers and state to demonstrate the UX.
- The architecture is designed to support multiple video providers in future phases.
- No database or authentication systems are integrated in Phase 1.
